# Koe — 右⌘を押して話すだけの日本語音声入力（macOS）

右⌘キーを押している間だけ聞き取り、話した文字を前面のアプリに入力する小さなメニューバーアプリです。

- 話している途中の文字が、画面下の吹き出しにリアルタイムで流れます（未確定の部分は灰色）
- 区切りごとに確定した文字から、入力欄に入っていきます
- 認識は macOS 26 から入った Apple の音声認識（`SpeechTranscriber`）を使い、**Mac の中だけで処理**します。音声も文字も外部に送りません
- 無料・登録不要

## 標準の音声入力との違い

FLEURS 日本語の読み上げ音声 100 発話（22.7 分）で、文字誤り率を比べた結果（2026-10、M1 Pro）:

| エンジン | 文字誤り率 | 処理時間 |
|---|---|---|
| **SpeechTranscriber（Koe が使うもの）** | **5.7%** | 17 秒 |
| Whisper large-v3-turbo（mlx-whisper） | 10.4% | 74 秒 |
| DictationTranscriber（従来の音声入力系） | 12.5% | 59 秒 |

読み上げ音声での結果なので、普段の話し言葉では数字が変わります。

## 動く環境

- macOS 26 以降（Apple シリコンで確認。Intel Mac は未確認）
- Xcode のコマンドラインツール（`xcode-select --install`）

## 作り方

```bash
git clone https://github.com/arasakisatoshi/koe.git
cd koe
./build.sh
open Koe.app
```

`Koe.app` はどこに置いても動きます。`/Applications` などに移すなら、移してから下の許可を出してください（移すと許可が外れることがあります）。

## 最初の設定（1 回だけ）

1. **アクセシビリティ**：システム設定 →「プライバシーとセキュリティ」→「アクセシビリティ」で Koe をオンにします。キーの見張りと貼り付けに使います
2. **マイク**：初めて右⌘を押したときの確認で「許可」を押します
3. Koe を終了して（メニューバーのマイクのアイコン →「Koeを終了」）、もう一度開きます

**作り直す（`./build.sh` を再実行する）と、アクセシビリティの許可が外れます。** 一覧の Koe を「−」で消し、「＋」で入れ直してください（オフ→オンだけでは戻らないことがあります）。

ログイン時に起動したい場合は、システム設定 →「一般」→「ログイン項目」に Koe.app を追加します。

## 使い方

- 文字を入れたい場所をクリックし、**右⌘を押したまま話して、話し終えたら離します**
- 押している間はメニューバーのアイコンが赤くなります
- 0.4 秒より短い押下と、右⌘＋他のキー（ショートカット）は無視します

## 知っておいてほしいこと

- 貼り付けにクリップボードを借ります。終わったら元の文字に戻しますが、**画像などテキスト以外をコピーしていた場合は消えます**
- 前面に確認ダイアログなどが出ていると、そこに貼り付けてしまいます
- Bluetooth ヘッドホンのマイクを使うと、通話モードへの切り替え待ちで出だしが遅れます。Mac 本体のマイクがおすすめです
- 日本語（ja-JP）固定です
- ログ（`~/Library/Logs/Koe/koe.log`）には、時刻・押していた時間・待ち時間・文字数・前面アプリだけを記録します。話した内容は残しません

## 権限について

Koe は、キーの監視と貼り付け（⌘V の送信）のためにアクセシビリティ権限を使います。強い権限なので、気になる場合は `main.swift`（約 300 行）を読んでから使ってください。ネットワーク通信は一切しません。

## 開発用

```bash
# 録音ファイルで認識だけ試す
Koe.app/Contents/MacOS/Koe --selftest 音声.wav

# 起動中の Koe にファイルを流して、前面アプリに貼り付ける（既定ではオフ）
defaults write org.arasaki.koe EnableDemo -bool true   # 有効化して Koe を再起動
xcrun swiftc -O koe-demo.swift -o koe-demo && ./koe-demo 音声.wav
```
